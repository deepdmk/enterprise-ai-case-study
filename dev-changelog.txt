## 2026-07-02 — Phase 1 review: rerank-after-fetch redesign + sync correctness

Full audit of phase-1-embed-space executed (31 fixes: critical bugs, sync
correctness, edge cases, improvements). Two design decisions from review:

Rerank-after-fetch redesign (search was broken by design — reranker asked
ChromaDB for documents the metadata-only index never stores, scoring None):
- ChromaDB stays metadata-only; SemanticRetriever slimmed to
  search_candidates() (no reranker, no documents include).
- SearchApp.search_async now orchestrates: k×multiplier candidates → parallel
  parent fetch (asyncio.gather, per-fetch error isolation) → chunk recovery
  by slicing content[char_start:char_end] → CrossEncoder rerank → dedup by
  parent doc → top-k. Stale offsets fall back to a window + log.
- Parent fetcher reconstructs combined text exactly like ingestion SQL
  (COALESCE(col,'') joined by ' '; NULL columns still contribute separators)
  so stored offsets can't drift.
- Production path now builds a real ParentDocumentFetcher (lazy pool init);
  previously always fell through to the mock.

Data freshness (decision: watermark incremental sync + nightly reconcile; NO
CDC — deletes may be visible up to ~24h, accepted and documented in README):
- Watermark = max observed data timestamp (was wall clock at completion);
  held on any per-table error so failed records retry next run.
- Incremental re-ingest deletes a doc's old chunks first (shrink-safe).
- New `--reconcile` mode in program3 deletes chunks whose source record is
  gone; intended as nightly cron (README has example crontab).
- Chunks tagged with embedding_model_version; search app warns on mismatch
  at startup (re-ingest after retrain).

Other fixes: similarity = 1 - distance (Chroma cosine, was /2 formula);
get_available_databases (wrong attr + metadata key) now feeds the Gradio DB
dropdown dynamically; per-session gr.State feedback (was shared instance
attrs across users); bounded feedback active-search dict; title_content pair
strategy implemented (was silent empty dataset) + unknown-strategy ValueError;
asyncpg param casts (id::text, $1::timestamptz); quoted SQL identifiers from
config; shared SELECT-builder dedup in database.py; parameterized LIMIT;
trainer honors evaluation_strategy/eval_steps/save_strategy + loss.scale;
empty-train-set guard; encode([]) returns (0, dim) array; chunk-offset
fallback retries from doc start; asserts → RuntimeError; datetime.now(UTC);
Gradio handlers async (sync wrapper + per-call event loop deleted);
ChromaDBClient reused between startup check and app.

Environment: phase-1-embed-space/.venv created (python3.13) with full deps —
repo-root venv (3.14) lacks the ML stack.

Tests: 71 passed (was 46; test_chunking un-mocked per fix 30, new suites for
pipeline watermarks/reconcile, parent fetcher reconstruction, SearchApp
orchestration, retriever candidates, empty encode).

## 2026-07-01 — Phase 0 review: bug fixes + phase0_infra namespace refactor

Full review of phase-0-infrastructure; fixed behavioral bugs, stale docs, and
restructured the package namespace. Cross-phase change (user opted in).

Environment:
- Recreated ./venv with /opt/homebrew/bin/python3.14 (old venv pointed at a
  removed /usr/local/opt/python@3.14 interpreter).

Behavioral fixes (phase-0):
- habitat_logging: removed ExceptionRenderer from console chain (was defeating
  ConsoleRenderer's own traceback rendering); basicConfig(force=True) so
  reconfiguration takes effect; logs to stderr; clear ValueError on bad level;
  new _HabitatBoundLogger proxies .exception() to stdlib .error() to kill a
  pre-existing double-traceback (stdlib Logger.exception re-rendered exc_info).
- base_settings: test_mode uses AliasChoices("test_mode", "PHASE0_TEST_MODE") —
  bare validation_alias silently dropped Settings(test_mode=True).
- model_registry: version parsing now supports both `_vN` suffix and canonical
  `{phase}/{unit}/{task}/vX.Y.Z` IDs (_extract_version); export filenames are
  filesystem-safe (never derived from raw model_id containing "/").
- storage (JSONStorage): atomic writes (temp file + os.replace); parent dir
  created on save even with auto_create=False; new set_if_absent() and
  mutate() primitives (single-lock read-modify-write).
- data/model registries: register/update_status/update_metrics now mutate
  under one lock and refresh cache from disk — fixes lost updates between
  concurrent registry instances. ExperimentTracker.start_experiment uses
  set_if_absent (TOCTOU fix).
- retry: RETRYABLE_EXCEPTIONS no longer includes OSError (superclass of both
  others; matched FileNotFoundError/PermissionError).
- phase_boundary_schemas: count validators no longer skip empty lists;
  ValidationResult renamed SchemaValidationResult (clashed with the
  registries dataclass of the same name).
- phase_integration: dead try/except ImportError fallback replaced with
  relative imports; PHASE0_AVAILABLE kept for API compat.
- RegisteredModel: new metrics dict field (schema_version 1.1); update_metrics
  no longer abuses tags with "metric:k=v" strings.

Namespace refactor:
- phase-0 packages moved under a single top-level package: phase0_infra/
  {registries,config,evaluation,habitat_logging}. Eliminates the generic
  top-level names (config, registries, ...) that shadowed each phase's own
  config package and forced importlib.spec_from_file_location hacks.
- All downstream imports updated (~110 files, phases 1-5 + root tests):
  from phase0_infra.<pkg>... ; importlib hacks in phase-{1,2,3,4}
  config/settings.py replaced with a normal import after sys.path insert.
- pyproject ships only phase0_infra*; pytest config merged into pyproject
  (pytest.ini deleted); run_tests.sh logging-rename workaround removed;
  README/USAGE.md stale `from logging.config import ...` instructions fixed.

Verification:

  tests/test_regressions.py covering the fixes above).
- root tests/test_phase_boundaries.py: 15 passed.
- downstream suites: phase-1 46 passed, phase-2 81 passed/1 skipped,
  phase-3 58 passed, phase-4 73 passed (httpx/fastapi/uvicorn installed).
