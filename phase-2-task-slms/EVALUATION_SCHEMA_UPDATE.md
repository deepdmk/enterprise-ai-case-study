## Metrics Mapping

### Phase-2 → Phase-0 Schema Mapping

| Phase-2 Field | Phase-0 Schema | Phase-0 Field | Notes |
|---------------|----------------|---------------|-------|
| `tokens_generated` | `TokenMetrics` | `output_tokens` | Direct mapping |
| `tokens_per_second` | `TokenMetrics` | `tokens_per_second` | Direct mapping |
| (estimated) | `TokenMetrics` | `input_tokens` | Estimated from input text length |
| `latency_ms` | `LoadMetrics` | `latency_ms` | Direct mapping |
| `format_compliance` | `QualityMetrics` | `format_compliance` | Direct mapping |
| `content_coverage` | `QualityMetrics` | `content_coverage` | Direct mapping |
| `section_coverage` | `EvaluationReport` | `notes` | Serialized to notes field |

### Fields Not Tracked in Phase-2

These phase-0 fields are set to `None` as they're not currently tracked:

**TokenMetrics:**
- `input_tokens` - Estimated using text length (1 token ≈ 4 chars)

**LoadMetrics:**
- `throughput_rps` - Not tracked
- `memory_mb` - Not tracked
- `gpu_utilization` - Not tracked

**QualityMetrics:**
- `factual_accuracy` - Not tracked
- `relevance_score` - Not tracked
- `human_preference_score` - Not tracked

**CostMetrics:**
- Entire schema - Not applicable for local inference

## Usage

```bash
cd /Users/shigoto/Projects/GitHub\ Repos/emergent-enterprise-ai/phase-2-task-slms

python -m src.program3_evaluation.main \

```

**Output files:**
- `evaluations/{unit}/{model}/evaluation_report.json` - Phase-2 format (backward compatible)
- `evaluations/{unit}/{model}/evaluation_report.md` - Markdown report
- `evaluations/{unit}/{model}/evaluation_report_phase0.json` - **Phase-0 standardized format**

### Programmatic Usage

```python
from src.program3_evaluation.evaluators.metrics import TaskSLMEvaluator

# Run evaluation
evaluator = TaskSLMEvaluator(model, tokenizer)
report = evaluator.evaluate_batch(examples)

# Convert to phase-0 format
phase0_report = report.to_phase0_report(
    report_id="eval_20260117_001",
    dataset_id="fundraising/portfolio_analysis_eval",
)

# Access standardized metrics
print(f"Quality: {phase0_report.quality_metrics.format_compliance:.1%}")
print(f"Latency: {phase0_report.load_metrics.latency_ms:.1f}ms")
print(f"Tokens/sec: {phase0_report.token_metrics.tokens_per_second:.1f}")
```

### Cross-Phase Comparison

```python
from evaluation.metrics_schema import EvaluationReport
from pathlib import Path

# Load phase-2 and phase-3 reports (both in phase-0 format)
phase2_report = EvaluationReport.model_validate_json(
    Path("evaluations/phase2/evaluation_report_phase0.json").read_text()
)
phase3_report = EvaluationReport.model_validate_json(
    Path("evaluations/phase3/evaluation_report_phase0.json").read_text()
)

# Compare using standardized metrics
quality_delta = (
    phase3_report.quality_metrics.format_compliance -
    phase2_report.quality_metrics.format_compliance
)
print(f"Quality improvement: {quality_delta:+.1%}")
```
